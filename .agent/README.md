# .agent — Artefactos operacionales del agente

Este directorial contiene los registros y apoyos que exigen los skills de trabajo
(ingeniero-android-web, senior-product-designer, vibe-work-onboarding) durante la
ejecucion de fases del proyecto.

Reglas acordadas con el propietario (2026-10-28):

- Ningun historial ni bitacora de acciones del agente vive en la raiz del repositorio.
- LOG/ registra las acciones del agente con el formato de linea del MAP.md.
- Los documentos de proyecto (MAP.md, DECISIONS/, DEBT.md, SNAPSHOT_vX.md, LOG/2026-10.md
  de hitos) permanecen en sus ubicaciones convencionales y solo se actualizan.
- Cada entrada de bitacora cita el skill que la exigio y el artefacto que produjo.
